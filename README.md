# Ferencore

A custom operating system built from scratch.

## Status

🚧 **Work in Progress** 🚧

Ferencore is currently under active development. This is a ground-up OS project, not based on existing distributions.

## Vision

Building a minimal, efficient operating system with complete control over every component. Focus on:

- **Minimalism**: Only what you need
- **Efficiency**: Low resource usage (~12MB target for core services)
- **Control**: Full transparency and customization
- **Performance**: Optimized for responsiveness

## Current Progress

- [ ] Kernel integration
- [ ] Basic boot process
- [ ] Init system
- [ ] Core utilities
- [ ] Package management
- [ ] Desktop environment
- [ ] Hardware support

## Design Goals

- Lightweight enough for 4GB RAM systems
- Modular architecture
- Clean, simple configuration
- Fast boot times
- Efficient memory usage

### Future: FSAL (Ferenlox Source Available License)

Once Ferencore becomes functional, it will transition to FSAL - a custom source-available license with these principles:

- **Free for personal/educational use**
- **Revenue sharing**: Users must contribute a percentage of earnings after crossing certain income thresholds
- **Redistribution requirement**: Any redistribution must maintain minimum stated terms to prevent abuse
- **Source available**: Full source code access with controlled commercial use

This model ensures sustainability while preventing exploitation.
